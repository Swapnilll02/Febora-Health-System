# 🏥 Febora Health Management System

A **web-based healthcare management system** designed to simplify and digitalize patient services such as appointment booking, doctor management, and medical report handling.

---

## 📌 Project Overview

The **Febora Health Management System** is a full-stack web application that allows users to:

* Register and securely log in
* View available doctors
* Book and manage appointments
* Upload and manage medical reports
* Update profile and password
* View a dynamic dashboard with real-time data

This system reduces manual effort and provides a **centralized, efficient, and user-friendly healthcare platform**.

---

## 🚀 Features

### 🔐 Authentication

* User Registration & Login
* Session Management

### 👨‍⚕️ Doctor Module

* View available doctors
* See specialization, experience, and hospital details

### 📅 Appointment Module

* Book appointments
* View appointment history
* Delete appointments

### 📄 Reports Module

* Upload medical reports
* View reports
* Delete reports

### 📊 Dashboard

* Real-time statistics:

  * Total Appointments
  * Available Doctors
  * Uploaded Reports

### ⚙️ Settings

* Update profile information
* Change password

## ⚙️ Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/your-username/Febora-Health-System.git
```

2. Import project into Eclipse

3. Configure Apache Tomcat server

4. Setup MySQL database:

* Create database
* Run SQL tables (users, doctors, appointments, reports)

5. Run the project on server
